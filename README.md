# LSPD Forum

Базовое Android-приложение для форума [whg124570.samp.date](https://whg124570.samp.date/). Форум открывается автоматически во встроенном браузере; отдельного поля поиска или ввода адреса нет. Веб-вход и переходы по HTTPS работают внутри приложения.

## Запуск

Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle. Для сборки требуется Android SDK Platform 36. Затем запустите конфигурацию `app` на эмуляторе или устройстве.

Для локальной сборки из терминала с установленным Android SDK выполните `gradle assembleDebug`.

## Ограничения

Это универсальная веб-оболочка, а не интеграция с API конкретного форума. HTTP-адреса блокируются. Нативные push-уведомления, загрузка файлов и отдельные функции форума можно добавить после определения движка и API.
